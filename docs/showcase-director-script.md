# PiHub 展示电影 —— 视觉导演脚本

> **定位**：以「动效电影」而非「录屏」的方式介绍 PiHub。所有镜头都是
> **真实组件在真实事件流上的演出**——打字机揭示、工具链整块收起、
> 最终总结渐入，都是生产渲染路径，不是视频特效。
>
> **执行载体**：demo 模式（`PIHUB_MODE=demo`）下页面自动播放剧本
> （`server/demo/showcase.ts`，SSE 标准事件流）；`npm run showcase:record`
> 可将其渲染为 mp4 供剪辑。本文档是导演视角的分镜与节奏设计。

## 导演阐述

一句话：**让 agent 的"思考-行动-交付"本身成为视觉主角**。

- 节奏：松弛有度——打字机慢条斯理，工具链利落干脆，收起瞬间果断。
- 配色语言：主色 `#005fb8` 只属于「正在发生的事」（光标、状态灯、
  进度）；完成的元素沉入灰色。观众永远知道 agent 现在在做什么。
- 声音（剪辑期）：打字机衬底（低频滴答）、工具完成（清脆单音）、
  收起（轻微"唰"）。无旁白也能看懂，有旁白更好。

## 分镜总表（约 30–40 秒）

| # | 时间 | 镜头 | 动效主角 | 主打特性 |
| --- | --- | --- | --- | --- |
| 1 | 0–2s | 空对话区，标题「π」 | 消息进入动画 | 开场 |
| 2 | 2–4s | 用户消息弹出 | rise-in 气泡 | 假装发送 |
| 3 | 4–6s | 思考状态 | 逐字渐现 + 波形 icon | 推理可见 |
| 4 | 6–12s | 工具链 ×3 | 工具卡逐个展开/完成 ✅ | 工具可追踪 |
| 5 | 12–20s | 最终回复 | **打字机逐字揭示** | 流式输出 |
| 6 | 20–24s | 整块收起 + 总结行 | **grid 收起动画 + 总结渐入** | 结算体验 |
| 7 | 24–28s | 点击展开 | 展开动画 + 内容完整 | 数据完整 |
| 8 | 28–34s | 切换镜头（剪辑）：多标签 / 统计 / 工程流 | 主色强调 | 特性矩阵 |

## 场景详解

### Scene 1 · 开场（0–2s）
- 画面：对话区空态（「π」标题 + 引导语）。
- 动效：无输入、无操作——**一切自动开始**（demo 播放器在 chat 挂载时
  自动触发，这是"假装"的边界：看起来像用户来了，其实是电影开场）。
- 字幕：「PiHub · 你的π，由此汇聚」

### Scene 2 · 假装发送（2–4s）
- 事件：user 消息 `message_start/end` 广播 → 前端消息进入动画（rise-in）。
- 文案：「看看 PiHub 能为我做什么」
- 导演注：用户气泡是**完整文本瞬间出现**（用户输入本来就该即时），
  与 assistant 的打字机形成节奏对比——**快的是人，慢的是机器在思考**。

### Scene 3 · 思考（4–6s）
- 事件：`thinking_delta` → 思考块折叠态 + 逐字渐现标签（已有动画）。
- 节奏：1.5s 停留，给观众"它在想"的呼吸感。

### Scene 4 · 工具链（6–12s）
- 事件：3 个 `toolcall_delta`（bash → get_commands → file_read），每个
  约 1s 间隔；随后 3 个 toolResult 依次回传（✅）。
- 动效：工具卡逐个出现，结果行 ✅/❌ 弹出。
- 导演注：工具是 PiHub 的"动作戏"——数量 3 个刚刚好，太多拖节奏。
- 字幕（可选）：「技能与工程流目录 · 本地会话 · 文件活动」

### Scene 5 · 打字机揭示（12–20s）★ 主打
- 事件：4 段 `text_delta` 分块到达；**前端 TypewriterText 以 ~90 字符/秒
  逐字揭示，主色光标闪烁**。
- 文案（四块连读）：
  1. 「PiHub 是 pi coding agent 的本地网页控制台——」
  2. 「多标签并行对话、会话树一键分叉、成本洞察、文件工作台，」
  3. 「还有 PiHub 独有的工程流编排：多步编排、审批闸门、实时时间线。」
  4. 「全部运行在你的机器上：仅监听 127.0.0.1，绝不读取你的凭据。」
- 导演注：**这段是电影的"高光"**。文字本身是特性清单，打字机让它
  变成"agent 在为你讲述"。剪辑时给足 8 秒，不要切走。
- 契约（🔒）：打字机只影响渲染，消息数据完整——复制/导出/展开永远
  拿到全文（冒烟脚本断言）。

### Scene 6 · 整块收起 + 最终总结（20–24s）★ 主打
- 事件：`agent_settled` → settled 单元**自动收起**（settledCollapse）：
  工具链、思考、过程作为一整块以 grid 行高过渡收回；
  「最终总结：…」一行**渐入** + `.....` 折叠标记。
- 导演注：这是 PiHub 与普通聊天窗最大的体验差异——**处理完就收桌，
  只留结论**。剪辑时在此镜头停 2s，让观众看到"收起"的动势。
- 字幕：「处理完成，只留最终总结」

### Scene 7 · 一键展开（24–28s）
- 点击总结行 → 整块展开动画，工具链/思考全部还原，内容一字不差。
- 字幕：「数据从未被裁剪」

### Scene 8 · 特性矩阵（28–34s，剪辑期素材）
- 多标签：侧边栏点击第二个会话 → 新标签打开（真实模式录制）。
- 统计：`Alt+3` 成本构成/按日趋势 SVG 图表。
- 工程流：自动化中心 → 运行一条 pipeline → 审批门 + 时间线。
- 收尾帧：品牌 + 「Local-first by design」卡片 + 仓库链接。
